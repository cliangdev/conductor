# Hooks: writing the headline

A hook is the line that makes a thumb stop. A tagline says what the brand is; a hook names a moment,
an object or a number the viewer recognises. Write several, score them, keep the best.

## Write 6 to 10 candidates

Mix the types. Do not write ten versions of one.

- **Situation / POV**: the moment the viewer is in. "which tab had the quote?"
- **Mechanism**: how it works, in one line. "paste a link. skip the rereading."
- **Enemy**: the thing it replaces or kills. "The spreadsheet nobody updates."
  Mechanism and Enemy hooks need an attitude to pass `voice.md`'s self-check: "the spreadsheet nobody
  updates" has one; a bare feature label ("Paste a link, get a summary") does not.
- **Exact result**: a specific number or time. "Invoices sent in 4 minutes, not 4 days."
- **Concept**: a visual metaphor the image carries, with the line finishing the thought. A photo of one
  chair at a long empty table, "this chair has been waiting since 9:15".

An approved line from the Knowledge page still wins when one fits. Quote it verbatim; use the
candidates to find the angle around it or when none fits.

## Score each 1 to 5

Same scale wording as the content studio's hook strength: 1 is a greeting or generic claim, 3 a clear
promise that could open any account's post, 5 a specific, surprising line a stranger gets in a second.

- **Hook strength**: would it stop a thumb?
- **Specificity**: does it name a moment, an object or a number?
- **Competitor test**: could a competitor run this unchanged? If yes, it fails; rewrite or drop it.
- **Reads like a person**: would someone say it out loud to a friend? Run `voice.md`'s self-check;
  a template frame ("X but Y"), a brand word or a line that describes the photo fails.

Exact numbers read as more credible than round ones: "11 minutes" over "10 minutes". One selling point
per line, written the way a person would say it.

## Keep 2 or 3

Keep the best two or three, and aim for about 8 words or fewer on the artwork. The rest are spare
hooks for variants (`variantOf`) or the caption. Run the chosen line through the brand's copy rules.

## Tagline vs. hook

| Tagline | Hook |
|---|---|
| Smarter scheduling for busy teams | this meeting could've been a link |
| Fresh food, delivered | the oven's still cold. dinner's here. |
| Save money on energy | our own bill dropped $38 last month |
| Learn faster with AI | ordered lunch in Spanish on day 30 |

Check the number and speed rows against the brand's claims rules before using a line like them: a number or a result has to be true.
